# @masseater.dev/song-format

このワークスペースは、楽曲ファイル形式 `.fu` を定義する。`.fu` ファイルは、独自の言語で記述したテキストである。ヘッダーでは、サンプル、キット、インストゥルメント、バス、トラック、ダッキング、マスターチェーンといった楽曲の音を宣言する。その後に小節を時系列に並べ、各小節にはトラックごとに 1 行の音価を書く。位置は相対的なもので、音符の位置は小節の順序とそれ以前の音価から決まる。小節ごとに拍子やテンポを変えられる。キー、コード、繰り返しの小節は音符から導くので、ファイルには書かない。この形式は将来の DAW の保存形式にもなり、DAW は言語サーバーを通じてファイルを編集する。

文法は `src/features/read-song/model/fu.langium` にある。変更したら `vp run grammar` を実行して `generated/langium` のパーサーを生成し直す。生成されたパーサーが古いままだと verify が失敗する。

`song-report <file>` は、楽曲ファイルから導いたキー、コード、繰り返しの小節を JSON 形式で出力する。楽曲を聴けない AI は、この出力を読んで自分が書いたものを確かめる。`fu-language-server` は、`.fu` ファイルの診断、補完、定義への移動をエディタに提供する。
