# @masseater.dev/song-format

このワークスペースは、楽曲ファイル形式 `.fu` を定義する。楽曲ファイルとは、拍子、テンポ、各パートの全音符といった楽曲の構成要素を書き出したJSONファイルである。音符によっては、歌詞、ピッチベンド、デチューンも書く。楽器、サンプル、ミキシング、オーディオ編集などは持たず、これらはDAWプロジェクトに属する。キー、コード、繰り返しの小節は音符から導くので、ファイルには書かない。

`src/entities/song/model/song.ts` の `SongSchema` が形式の定義である。これを変えたら `vp run schema` を実行して `generated/song.schema.json` を書き換える。そのファイルが古いままだとテストが失敗する。

`song-report <file>` は、楽曲ファイルから導いたキー、コード、繰り返しの小節をJSON形式で出力する。楽曲を聴けないAIは、これを読んで自分が書いたものを確かめる。
