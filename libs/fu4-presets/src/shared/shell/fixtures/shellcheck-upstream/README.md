# ShellCheck unit-test scripts

The `.in` scripts in this directory come from the unit tests in the source of [ShellCheck](https://github.com/koalaman/shellcheck) v0.9.0 (commit a526ee08290cc127bc1aa5a05e9b927af87b6ef3), and each `.out` file is ShellCheck 0.9.0's output for its script.
