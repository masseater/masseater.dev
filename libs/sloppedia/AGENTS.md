# Architecture Overview

Markdown 記事を Wikipedia 風に出す React コンポーネント集である。

## 1. システムの概略図

```text
[記事データ] --> [選出と並び替え] --> [メインページ / 記事ページ]
```

## 2. 中心の部品

### メインページ

説明: 新着とランダムピックアップの2枠を出す。すべての記事の一覧は出さない。

### 記事ページ

説明: 本文、Infobox、目次を組む。目次はサイドとインラインの両方に置く。

### カテゴリ

説明: 記事をカテゴリで束ねる。一覧と記事ページの両方から辿れるようにする。

### 記事データ

説明: 記事の型と並び替えを担う。新着順とピックアップの選出はここで決まる。ピックアップは決定的な選出で、乱数は使わない。記事の総数が変わると入れ替わる。

## 3. 開発とテストの環境

テスト: vitest で記事、見出し、ビューを確かめる。
制約: バンドルサイズの上限（size-limit）が verify に入っている。上限を上げるのではなく実装を軽くして収める。

## 4. デプロイと基盤

公開: [npm](https://www.npmjs.com/package/sloppedia)。バージョンを上げて publish.yml を手動で回す。

## 5. 用語集

ピックアップ: 記事の総数から決定的に選ばれる、おすすめ枠の記事である。
