# @masseater.dev/sashi

This workspace holds the shape of a reference on Sashi, the owner's shelf of references for what they want. The site in `apps/sashi` reads the files and `apps/sundries` writes them, so both take the schema from here.

A reference is one JSON file in the `content/` folder of `apps/sashi`. It holds a link and the owner's own words, never a copy of someone else's work.
