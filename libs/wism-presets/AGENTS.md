# @r_masseater/wism-presets

This workspace holds the official rule presets for wism. Each preset covers one concern: `fsd` for Feature-Sliced Design layers, slices and public APIs, `placement` for where files may sit, and `links` for Markdown link targets. It also holds the kind presets for workspaces, Rust crates and Agent Skills. It uses only the rule API of `@r_masseater/wism`, so it ships as plain TypeScript with no native code.
