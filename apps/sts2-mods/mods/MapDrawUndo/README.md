# MapDrawUndo

マップに描いた自分の線を `Ctrl+Z`(Mac は `Cmd+Z` も)で 1 本ずつ取り消す。消しゴムで消した跡も 1 本の線として取り消せる。

マップ画面を開いているときだけ効き、描いている途中は効かない。
マルチプレイでは、仲間もこの Mod を入れている場合に限り、取り消しが仲間の画面にも反映される。入れていない仲間の画面には線が残る。
ゲーム標準の「消去」ボタンと同じく、消せるのは自分の線だけである。

## 仕組み

ゲームは線 1 本を `Line2D` 1 つとして、プレイヤーごとの `SubViewport` に描いている(`NMapDrawings`)。
取り消しはその最後の `Line2D` を消し、専用のメッセージ `zMapDrawUndoMessage` で仲間に「最後の線を 1 本消した」と伝える。
線の同期は取りこぼしのある通信なので、取り消しは直前の線の送信が終わる 0.15 秒後に送り、
仲間側でまだ描きかけの線に取り消しが届いた場合は描き終わってから消す。

クラウドにゲームが無いため、実機では確かめていない。ゲームの更新でクラス構成が変わると、パッチは当たらない。
