# PeerSelectionHud

マルチプレイで、仲間が今何をしているかを画面の左に出す。一人プレイでは何も出ない。

仲間ごとに、今いる画面(マップ、報酬画面、カード選択中、デッキ確認、ポーズメニューなど)を出す。
カーソルを合わせている(または使おうとしている)カード・レリック・ポーションの名前と、マップで投票している行き先(段と列)も出す。

表示に使うのはゲームがもともと仲間と同期しているデータだけなので、仲間がこの Mod を入れていなくても動く。
ゲームが同期していない情報(報酬画面でどの報酬にカーソルを合わせているか、イベントの選択肢など)は出せない。

## 仕組み

`RunManager.Instance` のイベントを購読し、変化があったときだけ文字を書き換える。
画面と対象を選んでいる最中かは `PeerInputSynchronizer`、カーソルを合わせているものは `HoveredModelTracker`、マップの投票は `MapSelectionSynchronizer` から受け取る。
表示はゲームの画面より手前の `CanvasLayer` に置き、クリックは奥へ素通しする。

クラウドにゲームが無いため、実機では確かめていない。
