public リポジトリなら、標準の GitHub-hosted runner で動かす GitHub Actions は[分数の上限なく無料](https://docs.github.com/en/billing/concepts/product-billing/github-actions)で使える。無料の分数とストレージの枠があるのは private リポジトリだけで、[larger runner](https://docs.github.com/en/billing/reference/actions-runner-pricing) は public でも課金される。
