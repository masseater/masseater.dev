Markdown で書いた文書を、コマンド 1 つで顧客に渡せる日本語の PDF にする PFN の CLI ツールの[pfpdf](https://www.preferred.jp/ja/blog/tech/1798)。中身は Vivliostyle CLI と Chromium で、フォントを同梱しているので OS のフォントに左右されない。数式やコードハイライト、BibTeX の引用にも対応していて、テンプレートは 7 種類ある。
