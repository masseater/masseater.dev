ISUCON2026 で 3 人それぞれの Claude Code を Slack だけでつなぎ、ゴールを書いた GOAL.md と 1 行の連絡書式で協調させて 207,039 点を取った[カウシェの記事](https://zenn.dev/kauche/articles/f3736c660aab77)。ベンチマークとデプロイの衝突は担当を 1 つのエージェントに絞って消え、人間の仕事は「100 万点に届くには何が足りないか」のように目標を正すことに移ったという。
