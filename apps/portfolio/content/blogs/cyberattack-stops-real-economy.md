どこかのサービスがダウンし、他のサービスも連鎖的に次々とダウンし、資本主義が終わる日がきっとすぐにやってくるだろう。この世のあらゆるシステムはネットワークでつながっており、店舗のスタッフはそれらのネットワークと現実世界との単なるインターフェースに過ぎない。ネットワークの向こう側で停止すれば、たとえ店に人員や商品、設備が揃っていたとしても、何も売買できなくなる。不正アクセスは情報漏洩の事案と見なされがちだが、実際には実際の経済活動に直接支障をきたす。

2026年11月、ゲームセンターでのオンラインプレイを支えるALL.Netが不正アクセスによりダウンし、帰宅途中にゲームをプレイできなかった。運営元のセガ フェイブは、11月1日15時から各種サービスを停止し、11月2日18時時点でALL.Netタイトルのオンラインプレイ、AimeやPrizeON、さらには新規のSEGA ID登録までも停止していた。初期調査の結果、ユーザーまたはビジネスパートナー情報の漏洩は認められなかった[^segafave-allnet][^denfaminico-allnet]。それでも、ガンダムEXVSシリーズのプレイヤーたちは、オフラインで動作する筐体であっても次々とプレイ不能になると予想されていた[^exvs-offline]。店長もnoteで、マシンは問題なく動いていてもネットワークが止まると遊べない時代になっており、店舗側ではどうしようもない問題が増えている[^erina-note]と書いていた。

ゲームセンターでは「遊べなかったのが残念」で終わっているが、店舗というビジネス自体にも同じことが既に起きている。2026年7月、食品物流企業のニチレイが不正アクセスを受け、日本KFCは食材が届かなくなったこと、および全店舗が一時的に休業または販売停止となる可能性があることを発表した。全店舗が7月22日に通常営業に戻った[^impress-nichirei]。

攻撃を受けた当事者だけが止まるわけではない。2025年10月にアスクルがランサムウェアに感染した際、物流を委託していた無印良品とロフトもオンラインストアでの販売を停止した。良品計画独自のシステムは感染していなかった[^sakigake-askul]。今回のALL.Netの事件でも、バンダイナムコの太鼓の達人が巻き込まれた[^gamespark-allnet]。自覚すらしていない依存関係が、自分の現実を止める。

その連鎖は、取引関係のない競合他社にまで及んでいる。2025年9月29日、アサヒグループはランサムウェアの被害に遭い、受注および出荷が停止し、多くの工場で生産が停止した。セブン-イレブンのチューハイ「クリアクーラー」やファミリーマートの紅茶など、アサヒが契約して製造していたコンビニのプライベートブランドでは、出荷が止まることさえあった[^hokkaido-np-asahi-pb]。1カ月経っても回復の見込みはなく、10月末の時点でアサヒビールは通常商品の約1割しか出荷していなかった[^sakigake-asahi]。キリンはアサヒに代わって注文が殺到し、飲食店向けのビールを限定出荷したほか、年末ギフトセットの販売も中止した[^oanda-kirin]。攻撃を受けていなかったキリンは、アサヒの穴を埋めることができず、供給を絞らざるを得なかった。

連鎖に攻撃者すら必要ない。2024年7月、CrowdStrikeのセキュリティソフトウェアの不具合のあるアップデートにより、約850万台のWindowsマシンが停止した。それはWindowsマシン全体の1%にも満たない数だったが[^techcrunch-crowdstrike]、世界中の病院や航空会社、銀行が機能停止に追い込まれた。2025年10月、AWSとAzureで相次いで大規模な障害が発生した[^theregister-azure]。依存関係が少数のクラウドプロバイダーに集中しているため、それらのクラウドのいずれかがダウンすると、いかに丁寧に構築されていたとしても、その上で動作しているサービスも共に停止してしまう。

これらの障害は拡大しており、その間隔は狭まっている。

| 期間       | 何が止まったのか                                                               | 何が原因だったのか                           |
| ---------- | ------------------------------------------------------------------------------ | -------------------------------------------- |
| 2024年7月  | 世界中で約850万台のWindowsマシン                                               | 不具合のあるセキュリティソフトのアップデート |
| 2025年9月  | アサヒの出荷品、コンビニのプライベートブランド、キリンの飲食店・バー向けビール | アサヒへのランサムウェア                     |
| 2025年10月 | 無印良品とLOFTのオンラインストア                                               | ASKUL（物流請負業者）におけるランサムウェア  |
| 2025年10月 | AWSおよびAzure上で動作するサービス                                             | クラウド障害                                 |
| 2026年7月  | 全KFC店舗                                                                      | 食品物流企業「ニチレイ」への不正アクセス     |
| 2026年11月 | 全国のゲームセンターにおけるALL.Netタイトル                                    | ALL.Netへの不正アクセス                      |

僕が見つけられた範囲でも、2024年7月以降は1年以上の間隔があったが、2025年秋以降は数ヶ月おきに起きている。停止の範囲も、攻撃を受けた企業の取引先から、取引のない競合他社、さらには攻撃者が全くいない世界的な障害へと広がっている。一方で、システムは互いに接続される方向へ進み続け、依存関係も少数のプロバイダーへと集まり続けている。

資本主義が終わる日は、遠い未来の話ではない。どの障害も、数日か数ヶ月で復旧し、ニュースになり、そして忘れ去られる。しかし、障害が起きるたびに連鎖の影響範囲は広がり、いつの日か、どこかで一つの障害が、復旧するより先に経済を止めることになるだろう。こうした障害の積み重ねの果てに、その日はもうすぐやってくる。
