MIDI ファイル 12 本を `midi-to-fumx`（[#1287](https://github.com/masseater/masseater.dev/pull/1287)）で `.fumx` に変換し、イベント単位で突き合わせた結果である。

## 突き合わせ方

`midi-to-fumx` は `.fumx` を書き出した後、[fumx-parser](https://github.com/masseater/masseater.dev/tree/main/libs/fumx-parser) の `readSong` で読み直す。読み直したノート、コントローラー、テンポ変更、歌詞、マーカーを、MIDI ファイルのイベントと多重集合として比べ、イベントが 1 つでも欠けるか余るとコマンドが失敗する。

MIDI ファイルは [Mutopia Project](https://www.mutopiaproject.org/) と [@tonejs/midi](https://github.com/Tonejs/Midi) のテスト用ファイルから取った。リポジトリには置いていない。

## 12 本の結果

## @tonejs/midi との照合

@tonejs/midi で読んだノートは、12 本のうち 11 本で変換結果と一致した。symphony_7_2_singletrack の差は、同じ音程で重なったノートをどのノートオフと組にするかの方針の違いだけで、`midi-to-fumx` は先に鳴った音から順に組にしている。concerto_for_orchestra_1 では、@tonejs/midi のコントロールチェンジの数がファイル内のイベントの実数より 1 つ少なく、変換結果の数は実数と一致した。

## 変換のために足した構文

| 構文                                    | 書くもの                                        |
| --------------------------------------- | ----------------------------------------------- |
| `track.cc N:`                           | コントロールチェンジ N                          |
| `track.bend:`                           | 半音単位のピッチベンド（`+0.5st` など）         |
| `track.pressure:`、`track.pressure C4:` | チャンネルとポリフォニックのアフタータッチ      |
| `track.program:`                        | プログラムチェンジ                              |
| 小節の中の `tempo:` の行                | 小節の途中でのテンポ変更                        |
| ノートとヒットの `off 0.x`              | リリースベロシティ                              |
| ヒットの `tie`、長さ `0/1`              | 次の小節へ続くドラムのヒットと、長さ 0 のノート |

ピッチベンドは値をそのまま書き出す。pitchBendTest の最初の小節は `acoustic-grand-piano.bend: 0st 19/1920, +0.079833984375st 19/1920, ...` で始まる。

## 残らないもの

| MIDI の情報                                                          | 扱い                                                          |
| -------------------------------------------------------------------- | ------------------------------------------------------------- |
| システムエクスクルーシブ、歌詞とマーカー以外のテキストのメタイベント | 捨てる                                                        |
| 調号                                                                 | 書かない。`.fumx` は調を音から導く                            |
| 小節の途中にあるマーカー                                             | その小節の頭に寄せる                                          |
| 音色                                                                 | General MIDI のプログラム番号を持つ仮の `gm` プラグインにする |
| ドラムの音                                                           | 仮のサンプルのパスを指す                                      |

`.fumx` にはまだ音を鳴らすレンダラーがないので、この突き合わせは音ではなくイベントの比較である。
