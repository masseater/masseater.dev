masseater.devは、ビルドしたもののほぼすべてを保管しているモノレポだ。2026年11月7日から、他のリポジトリを1つずつそこに移した。11月18日時点で、約110のワークスペースがある。これらは `apps`、`libs`、`tools`、`infra` 配下にあり、TypeScript と Rust で記述されている。9,023個のファイルを追跡しており、履歴には1,339件のコミットがある。

## Git

Git側は小規模だ。11月18日にクラウドコンテナからクローンを計測した。

| クローン                        | サイズ | 時間  |
| ------------------------------- | ------ | ----- |
| フル (`git clone --bare`)       | 107 MB | 4.4 s |
| blobless (`--filter=blob:none`) | 4.5 MB | 0.8 s |

ワーキングツリー内のファイルは合計137 MBである。いくつかのバイナリファイルが履歴の大きな割合を占めている。

| ファイル                                                        | パック内のサイズ |
| --------------------------------------------------------------- | ---------------- |
| Next.js tarball（ベンダー提供のattwコードのテストフィクスチャ） | 20.4 MB          |
| wismのネイティブバイナリ（3回コミット済み）                     | 合計14.8 MB      |
| サイト上のダンス動画                                            | 2.7 MB、2回      |

wismバイナリはビルド出力である。y8およびfu4は、`.gitignore` を使用して同様のバイナリをGitから除外する。wismにその行がなかったため、リビルドのたびに約5MBのコピーが履歴に追加された。11月18日にGitから削除した。

## node_modules

`node_modules` は 4.5 GB を消費する。11月14日時点で、lockfileには2,681個のパッケージが含まれていた。合わせて4.49 GBだった。最大の直接依存関係は `@huggingface/transformers` で、458 MB だった。続いて、`@anthropic-ai/claude-agent-sdk`（352 MB）と`@effect/tsgo`（296 MB）があった。Renovateは依存関係の中で最もパッケージ数が多く、その数は299個だった。`renovate.json`を検証するためだけそこにあった。これを削除したことで、合計は2,381個のパッケージ、4.34 GBとなった。

ロックファイルには2,553件のエントリがある。`vp install --frozen-lockfile` を実行するたびに、pnpm はレジストリのサプライチェーンポリシーに照らしてすべてのエントリを確認する。CIでは、検証レコードがキャッシュされるまで、1ジョブあたり65〜165秒かかった。

## Rustのビルド出力

Rustのワークスペースは、他のどのワークスペースよりも多くのデータを生成する。クラウドセッションの書き込み枠は約40GBである。開発およびテストプロファイルで `debug = 0` を指定しないと、`target/debug` は 14 GB にまで膨れ上がった。`debug = 0` を追加したことで、3.4 GBまで削減された。クレートが増えて、11月16日には再び15GBまで育った。その後、ディスクが一杯になったため、ルートの `vp test run` が SIGBUS で失敗した。

11月17日、`target/debug`は750クレート、3,005ビルド、合計8.3 GBを保持した。各cargoタスクは `-p <package>` で実行されるため、各パッケージで異なる feature の組が解決され、cargoは組ごとに同じクレートをビルドする。Cargo 1.100.0 では、`resolver.feature-unification` を用いてワークスペース全体の feature を統一できるが、`-Zfeature-unification` を付けたときだけ使える。masseater.dev は開発プロファイルのデバッグ情報とインクリメンタルビルドを無効にし、デスクトップでしか動作しない4つのTauriアプリから `staticlib` と `cdylib` を削除した。キャッシュなしのcargo タスクの総時間は、930秒から723秒に短縮された。

CIでは、リポジトリをセットアップするすべてのジョブが、約2.2 GBのpnpmストアを復元する。その復元には約50秒かかる。
