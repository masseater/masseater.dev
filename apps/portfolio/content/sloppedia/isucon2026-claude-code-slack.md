**ISUCON2026 のカウシェのチーム**は、ISUCON2026 に出場したカウシェの3人のチームで、各自の Claude Code を Slack だけでつないで協調させた[^kauche]。

## 方法

ゴールを書いた GOAL.md と、1行の連絡書式で3つのエージェントを協調させ、207,039点を取った[^kauche]。

## 分かったこと

ベンチマークとデプロイの衝突は、担当を1つのエージェントに絞ることで消えた。人間の仕事は「100万点に届くには何が足りないか」のように、目標を正すことに移ったという[^kauche]。
