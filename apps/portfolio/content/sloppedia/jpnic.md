JPNIC（日本ネットワークインフォメーションセンター）は、日本の IP アドレスと AS 番号の登録を管理する一般社団法人である。アジア太平洋地域を受け持つ [APNIC](/sloppedia/apnic) の下で、国別インターネットレジストリ（NIR）として働く[^history]。「インターネットの円滑な運用のために各種の活動を通じてその基盤を支え、豊かで安定したインターネット社会の実現を目指します」を活動理念に掲げる[^about]。

かつては .jp のドメイン名の登録も受け持っていたが、2002年に自ら設立した [JPRS](/sloppedia/jprs)（日本レジストリサービス）へ移した。それ以降は、JP ドメイン名が公共の利益に沿って運用されているかを日本政府とともに確かめる役に回っている[^ikan]。ほかに [Internet Week](/sloppedia/internet-week) の主催や、インターネットガバナンスの国際的な議論への参加も続けている[^about]。

## 歴史

### JUNET から JNIC へ

源流は、1984年に東大・東工大・慶大を結んだ研究用のネットワーク [JUNET](/sloppedia/junet) にある。JUNET は UUCP で動き、.JUNET というドメイン名を使っていた[^history]。1988年に始まった [WIDE プロジェクト](/sloppedia/wide-project) が TCP/IP の実験環境を作り、1989年からはドメイン名が「大学名.AC.JP」のような階層を持つ .JP の形へ移っていった[^history]。

この時期、.JP の登録はボランティアの管理者の集まり junet-admin が、DNS の運用は bind-admin が担っていた。IP アドレスの割り当ては、1989年からネットワークアドレス調整委員会が受け持った[^history]。1991年12月1日に発足した JNIC は、.JP の登録と DNS の運用を引き継いだ。1992年6月には IP アドレスの割り当ても引き継いでいる[^history]。

1993年4月9日、JNIC はネットワークのプロジェクトを会員とする任意団体 JPNIC に改組された[^history]。同じ年の9月には APNIC のパイロットプロジェクトが始まった。APNIC はもともと[村井純](/sloppedia/murai-jun)と平原正樹が提案したもので、当初は JPNIC の中の作業部会で日本人のメンバーが IP アドレスを割り当てていた[^history]。

### 社団法人化と JP ドメイン名の移管

1997年3月31日、JPNIC は社団法人になった[^about]。同じ年の12月には第1回の Internet Week が開かれ、1999年からは JPNIC が主催している[^history]。初代の理事長は村井純で、2005年に後藤滋樹、2022年に江崎浩へ交代した[^history]。

1990年代の後半、インターネットが急に広がると、JP ドメイン名にも使い勝手のよさが求められるようになった。JPNIC は会員との議論を経て、2000年12月22日の総会で、新しい会社を作って JP ドメイン名の登録管理業務を移すと決めた[^ikan]。4日後の12月26日に JPRS が設立された。2001年2月には、1つの組織が複数を取れる汎用 JP ドメイン名（example.jp の形）の登録を JPRS が始めた[^history]。

移管には ICANN の承認が要った。.jp の管理者として委任を受けていたのは、当時の JPNIC 理事長の村井純個人である。ICANN は村井と日本政府に確かめ、両者は JPRS を承認する書簡を返した[^ikan]。2002年2月27日に ICANN と JPRS が ccTLD スポンサ契約を結び、4月1日に登録管理業務は JPRS へ移った[^ikan]。

### 一般社団法人へ

2013年4月1日、JPNIC は社団法人から一般社団法人（非営利型）に移った[^history]。税制の上で、構成員に利益を分けない法人として扱われる。

2026年6月15日の第79回通常総会で役員が改選され、江崎浩が理事長を続けることになった。副理事長は曽根秀昭と長谷部克幸である[^officers]。

## IP アドレスの管理

### レジストリの階層

IP アドレスは世界全体で階層を作って配られている。アジア太平洋地域では APNIC が、日本の中では JPNIC と、JPNIC が IP 指定事業者と呼ぶ事業者が管理を担う[^ipv4-blog]。IP 指定事業者は JPNIC から受けたアドレスを、自分のネットワークや顧客に割り当てる。

JPNIC のブログによると、2026年11月4日の時点で、APNIC が管理する IPv4 アドレスのうち日本向けは約1億8,900万ある[^ipv4-blog]。そのうち約1億3,200万が JPNIC の管理下にあり、約1億200万が IP 指定事業者へ割り振られている。IP 指定事業者は2001年の約250組織から増え続け、今は500組織を超える。そのうち約7割が IPv6 アドレスの割り振りも受けている[^ipv4-blog]。

IP アドレスの配り方の決まりは、JPNIC オープンポリシーミーティングで話し合う。2001年に第1回を開き、合意した内容は APNIC に提案する[^history]。第51回は2026年11月24日に開かれる[^jpopm51]。

### IPv4 アドレスの在庫枯渇

2011年2月3日に IANA の IPv4 アドレスの在庫が尽き、4月15日には APNIC と JPNIC の在庫も尽きた。JPNIC はこれに合わせて IPv4 アドレスの管理の方針を変えた[^history]。同じ年の8月には、組織の間で IPv4 アドレスを移す移転申請を受け付け始めた。2015年には移転を望む組織の一覧を出すサービスも始めている[^history]。返却された在庫からの新たな割り振りも、2019年7月3日で終わった[^history]。

### 維持料の見直し

2026年4月の請求分から、IP アドレスと AS 番号の維持料が上がった[^fee]。JPNIC は理由として、APNIC から請求される会費が増えたことと、人件費や保守料の高騰を挙げる。今の料金体系は2012年度に作ったもので、その収入では IP アドレス事業を保つのが難しくなりつつあるという[^fee]。

計算式の数値は、2023年から料金を見直している APNIC に合わせて変えた。たとえば /24 の維持料は税込みで55,000円から60,500円になり、2028年度には62,944円まで段階的に上がる[^fee]。

### 経路と WHOIS

JPNIC は、インターネットの経路の情報を登録するデータベース JPIRR を2002年から試験運用し、2006年から正式なサービスとして提供している[^history]。[RPKI](/sloppedia/rpki) の ROA で不正な経路を防ぐためのガイドラインも2024年11月に出し、2026年3月に改訂した[^history][^topics-2026]。

登録情報を引く [WHOIS](/sloppedia/whois) は、今も Web 版を Shift_JIS、コマンド版を ISO-2022-JP で返している。JPNIC は2027年7月ごろに、表示の文字コードを UTF-8 へ切り替える予定である[^whois-utf8]。2027年1月から6月は、新しい環境を whois-new.nic.ad.jp で並行して動かす[^whois-utf8]。

## JP ドメイン名との関わり

登録管理を JPRS へ移した後も、JPNIC は JP ドメイン名に関わり続けている。ドメイン名には公共の資源という面があり、民間の会社が管理するなら公共性と中立性を確かめる者が要るからである[^ikan]。JPNIC が日本のインターネットコミュニティの代表として、日本政府とともにこの確認を担うことは、ICANN と JPRS の契約に書かれている[^ikan]。

具体的には、JPRS が公共性を保つ責任を果たしているかを確かめる業務と、JP ドメイン名の登録データを第三者に預けるデータエスクローの業務を受け持つ[^domain-intro]。

ドメイン名と商標の争いを裁く JP-DRP（JP ドメイン名の紛争処理方針）を作って改めるのも JPNIC である[^ikan]。JP-DRP は ICANN の UDRP を手本に作られ、2000年10月19日に施行された[^history]。2026年4月には改正した手続規則を施行し、3月には制度の解説の改訂版と、2018年から2024年の裁定例をまとめた報告書を出した[^jp-drp]。

## 普及と人材の育成

Internet Week は、インターネットの研究、構築、運用に関わる人が集まって学ぶ非商用のイベントである。1997年に始まり、2026年の会は11月19日から27日まで、東京の両国の会場とオンラインで開かれる。30回目となる2026年のテーマは「AI時代を生き抜く術(すべ)を学べ」で、約30のプログラムを並べる[^iw2026]。2026年6月30日と7月1日には、特別版の Internet Week Showcase を静岡で開いた[^iwsc-shizuoka]。

人材の育成では、総務省の令和7年度の事業として、ネットワークエンジニアの確保と育成についての調査を受託した。結果は2026年7月に総務省の Web サイトで公表された[^engineer-survey]。2026年11月には、文部科学省が示した次の学習指導要領に向けた審議まとめへ意見を出した。情報技術を使う力だけでなく、情報基盤を作って保つ力を育てるよう求めている[^curriculum]。

## インターネットガバナンス

JPNIC は2000年に ICANN の横浜会合を主催した。2019年には、ICANN の会議が19年ぶりに日本で開かれた[^history]。2023年に日本で開かれた [IGF](/sloppedia/internet-governance-forum) に向けては、国内の活動を盛り上げるチームを組んだ[^history]。

2014年からは日本インターネットガバナンス会議（IGCJ）の事務局を務めていた。IGCJ の活動は、新たに作られた日本インターネットガバナンスフォーラム支援機構（一般社団法人）が支える日本インターネットガバナンスフォーラムに引き継がれた。IGCJ のメーリングリストは2026年9月1日に止まった[^igcj]。2027年には、この支援機構をホストとして、アジア太平洋地域の IGF（APrIGF）が日本で開かれる[^aprigf]。

2026年6月には、総務省のオンラインカジノへのアクセスを抑える検討会の報告書案に意見を出した。DNS のブロッキングは憲法の定める通信の秘密を侵す手法であり、回避の手段も次々と出てくると指摘している[^casino]。同じ年の9月10日には、不正行為の通知に責任の連鎖を持たせることを目指す香港の非営利法人 Trusted Notifier Network と覚書を結び、支持組織として加わった[^tnn]。JPNIC は通知や対応そのものは担わず、政策対話や普及啓発で関わる[^tnn]。
