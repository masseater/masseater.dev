日本のインターネットと情報の機関は、日本のインターネットと情報システムの基盤を支える組織の総称である。この一覧では、IP アドレスやドメイン名を管理する組織、ネットワークをつなぐ事業者、セキュリティの対応や研究を担う組織、行政機関、業界団体を役割ごとに並べる。一般の利用者に回線を売る通信事業者やプロバイダーそのものは載せない。

法人の形はさまざまである。国の機関や独立行政法人のほか、一般社団法人、株式会社、任意の研究コンソーシアムが同じ基盤の別々の部分を受け持っている。2025年から2026年にかけては、国のサイバーセキュリティの司令塔の改組や、IPA の役割の広がりといった動きがあった。

## 番号と名前の管理

| 名前                                              | 種別         | 役割                                                                                   |
| ------------------------------------------------- | ------------ | -------------------------------------------------------------------------------------- |
| [JPNIC](/sloppedia/jpnic)                         | 一般社団法人 | 日本の IP アドレスと AS 番号の登録を管理する国別インターネットレジストリ[^jpnic-about] |
| [JPRS](/sloppedia/jprs)（日本レジストリサービス） | 株式会社     | .jp のドメイン名の登録を管理するレジストリ。2000年12月26日に設立された[^jprs]          |

JPRS は、JPNIC が JP ドメイン名の登録管理業務を移すために設立した会社である。2002年4月に業務を引き継いだ[^jpnic-ikan]。JPNIC は今も JPRS の主な株主の1つに名を連ねる[^jprs]。一方で JPNIC は、JP ドメイン名が公共の利益に沿って運用されているかを、日本政府とともに確かめる立場にもある[^jpnic-ikan]。

## 相互接続

ネットワークどうしがトラフィックを交換する場所をインターネットエクスチェンジ（IX）と呼ぶ。日本の主な IX は民間の会社が運営している。

| 名前                                                      | 種別     | 役割                                                                                        |
| --------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------- |
| [JPNAP](/sloppedia/jpnap)（インターネットマルチフィード） | 株式会社 | IX のサービス JPNAP と、IPv6 の接続サービス transix を提供する[^mfeed]                      |
| [JPIX](/sloppedia/jpix)                                   | 株式会社 | IX のサービスと、v6プラスなどの IPv6 の接続サービスを提供する。KDDI などが株主である[^jpix] |
| [BBIX](/sloppedia/bbix)                                   | 株式会社 | 2003年に設立された IX の事業者。香港やシンガポールなどアジアにも拠点を持つ[^bbix]           |

## セキュリティ

| 名前                                      | 種別         | 役割                                                                                                      |
| ----------------------------------------- | ------------ | --------------------------------------------------------------------------------------------------------- |
| 国家サイバー統括室（NCO）                 | 内閣官房     | 官民のサイバーセキュリティの司令塔。2025年7月1日に NISC を改組して置かれた[^nco]                          |
| [IPA](/sloppedia/ipa)（情報処理推進機構） | 独立行政法人 | 情報セキュリティの対策、IT 人材の育成、IT の国家試験の実施などを担う[^ipa-about]                          |
| [JPCERT/CC](/sloppedia/jpcert-cc)         | 一般社団法人 | 国内のインシデントの報告を受け、対応を支援する。特定の政府機関や企業から独立した中立の組織である[^jpcert] |
| ICT-ISAC                                  | 一般社団法人 | 通信事業者、放送事業者、ソフトウェアベンダーなどがセキュリティの情報を共有する場[^ict-isac]               |
| JC3（日本サイバー犯罪対策センター）       | 一般財団法人 | 産業界、学術機関、法執行機関がサイバー犯罪の脅威の情報を持ち寄る非営利団体[^jc3]                          |
| JNSA（日本ネットワークセキュリティ協会）  | NPO 法人     | セキュリティの事業者などが集まり、ワーキンググループで報告書や教材を作る[^jnsa]                           |

国家サイバー統括室の前身の NISC は、内閣サイバーセキュリティセンターの略である。改組は、能動的サイバー防御を導入する法律の成立を受けたもので、トップには内閣サイバー官が置かれた[^nco]。

IPA は2026年6月5日、英語の名称を Information-technology Promotion Agency, Japan から Innovation Platform Agency, Japan に改めた。日本語の名称と略称は変えていない[^ipa-brand]。IPA は理由として、AI、データ、半導体などの戦略技術への支援、サイバー安全保障へと役割が広がったことを挙げる[^ipa-brand]。2025年の法改正で次世代半導体の量産に向けた金融支援も担うことになり、2026年6月までに Rapidus へ計2,500億円を出資した[^ipa-rapidus]。

## 研究と学術ネットワーク

| 名前                                         | 種別               | 役割                                                                                          |
| -------------------------------------------- | ------------------ | --------------------------------------------------------------------------------------------- |
| [NICT](/sloppedia/nict)（情報通信研究機構）  | 国立研究開発法人   | 情報通信を専門とする国の唯一の公的研究機関。サイバーセキュリティ研究所などを持つ[^nict]       |
| NII（国立情報学研究所）                      | 大学共同利用機関   | 大学や研究機関をつなぐ学術情報ネットワーク [SINET](/sloppedia/sinet) を構築し運用する[^sinet] |
| [WIDE プロジェクト](/sloppedia/wide-project) | 研究コンソーシアム | 1988年に設立された、インターネットの技術と標準を研究するコンソーシアム[^wide]                 |

SINET は2022年4月から SINET6 として運用されている。400Gbps の回線で約1,000の大学や研究機関をつなぐ[^sinet]。WIDE プロジェクトは、1986年に UNIX を研究する大学の研究者が集まった WIDE 研究会から始まった。IETF の会議を日本で開くことなどを通して、世界のインターネットに関わってきた[^wide]。

## 行政

| 名前       | 種別         | 役割                                                                         |
| ---------- | ------------ | ---------------------------------------------------------------------------- |
| デジタル庁 | 国の行政機関 | デジタル社会を作るための司令塔として、官民のデジタルの基盤を整える[^digital] |

総務省、経済産業省、警察庁なども、それぞれの所管でインターネットに関わる。JPNIC の調査の受託や、オンラインカジノへのアクセスを抑える検討会のように、上の機関と行政が組む場面も多い[^jpnic-topics]。

## 業界団体とコミュニティ

| 名前                                               | 種別         | 役割                                                                                                                |
| -------------------------------------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------- |
| JAIPA（日本インターネットプロバイダー協会）        | 一般社団法人 | インターネットのプロバイダーの業界団体[^jaipa]                                                                      |
| JIPDEC（日本情報経済社会推進協会）                 | 一般財団法人 | 1967年に設立された。プライバシーマーク制度を運営する[^jipdec]                                                       |
| 日本インターネットガバナンスフォーラム（日本 IGF） | フォーラム   | インターネットガバナンスを国内で議論する場。2027年には支援機構がアジア太平洋地域の IGF のホストを務める[^japan-igf] |
| ISOC Japan Chapter                                 | 支部         | Internet Society の日本の支部。ワークショップや IETF の報告会を開く[^isoc-jp]                                       |

日本 IGF は、JPNIC が事務局を務めた日本インターネットガバナンス会議（IGCJ）などの活動を引き継いだ。新たに設立された支援機構の一般社団法人が支える形になっている[^jpnic-igcj]。
