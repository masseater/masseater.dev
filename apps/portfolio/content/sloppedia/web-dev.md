web.dev は、Google が運営する Web 開発者向けのサイトである。美しく、誰でも使えて、速く安全な Web サイトを、どのブラウザでも動く形で作る手助けを掲げている。記事を書くのは、Chrome チームのメンバーと、ユーザー補助やパフォーマンスやデザインを専門とする外部の専門家である[^webdev]。

## 内容

### 指針と特集

トップページには、AI を使った Web ファーストの体験、Core Web Vitals の指標になった Interaction to Next Paint（INP）の測定と最適化、本人確認と支払いの最新機能のような特集が並ぶ[^webdev]。

### Web プラットフォーム

HTML、CSS、JavaScript など、Web プラットフォームの各部分を自分の速さで掘り下げる道筋を用意している[^webdev]。

### 講座

初心者向けに「HTML を学ぶ」「CSS を学ぶ」「JavaScript を学ぶ」の講座がある。プログレッシブ Web アプリの講座もある[^webdev]。

### ブログ

新機能や Baseline の更新、AI、Core Web Vitals などの話題は、同じサイトの中の [web.dev ブログ](/sloppedia/web-dev-blog)で発信している[^webdev]。

## 言語

日本語などの各言語版は、Google が AI で翻訳したもので、誤りを含む場合があると断り書きがある[^webdev]。

[^webdev]: Google「[web.dev](https://web.dev/?hl=ja)」。
