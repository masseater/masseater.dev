GitHub Actions の料金では、GitHub Actions の課金のうち、リポジトリの公開範囲による違いを扱う。

## public リポジトリ

public リポジトリでは、標準の GitHub-hosted runner で動かす GitHub Actions を、分数の上限なく無料で使える[^billing]。

## private リポジトリ

無料の分数とストレージの枠が設けられているのは private リポジトリだけである[^billing]。

## larger runner

larger runner は public リポジトリでも課金される[^pricing]。

[^billing]: GitHub「[GitHub Actions billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions)」GitHub Docs。

[^pricing]: GitHub「[Actions runner pricing](https://docs.github.com/en/billing/reference/actions-runner-pricing)」GitHub Docs。
