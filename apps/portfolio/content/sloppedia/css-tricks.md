CSS-Tricks は、Web のフロントエンドの技術を扱う記事サイトである。記事、チュートリアル、まとまったガイド、ニュースレターを出している[^about]。2007年に Chris Coyier が始め、のちに200人を超える書き手が寄稿する場になった[^about]。

2022年3月にクラウドの DigitalOcean へ売られた[^acquired]。その後、運営の人員を切られて2度休眠した[^coyier-2024][^vale]。2026年10月26日、編集長の Geoff Graham がサイトを買い取り、独立したサイトに戻ったと発表した[^new-owner]。

## 歴史

### Chris Coyier の時代

Chris Coyier は2007年7月4日に最初の記事を出した[^about]。2012年には Kickstarter で資金を集め、CSS-Tricks を本業にした[^about]。2015年に Marie Mosley、Robin Rendle、Sarah Drasner、Geoff Graham が加わった[^about]。Geoff Graham は編集長として、広告の取りまとめとサイトの管理も担った。Robin Rendle はニュースレターを業界で必読の便りに育てた[^acquired]。

Coyier はこの間、コードを書いて共有するサービス CodePen も共同で運営していた。売った理由の1つに、両方を回すのが重荷だったことを挙げている[^coyier-2024]。

### DigitalOcean の時代

2022年3月15日、Coyier は CSS-Tricks が DigitalOcean に加わると発表した[^acquired]。DigitalOcean はサイトと記事をそのまま残し、フロントエンドの質の高い記事を出し続けると約束した。Coyier は移行の間だけ相談役として残った[^acquired]。Coyier は、DigitalOcean が広告を外すことや、Geoff Graham を残すことを、売る判断の材料にしたと書いている[^coyier-2024]。

およそ1年後の2023年2月、DigitalOcean は Geoff Graham を含め、記事とコミュニティに関わる人を全員解雇した[^coyier-2024][^vale]。Coyier によると、その1か月後に最後の記事が出て、サイトは止まった[^coyier-2024]。DigitalOcean は2024年6月に Geoff Graham を再び雇い、記事の公開が再開した[^vale]。

### 2026年の休眠と独立

2026年9月の時点で、CSS-Tricks は再び動きを止めていた。DigitalOcean からの説明はなかった[^vale]。寄稿者の Declan Chidlow は、同じころ DigitalOcean が Omarchy に300万ドルの寄付を約束したことを挙げ、自社のサイトを放っておく姿勢を批判した[^vale]。

Coyier は9月21日、サイトが残ってほしいと書き、関係者に話をする用意があると述べた[^coyier-2026]。寄稿者の Eric Bailey は、CSS-Tricks を協同組合として運営する案を出した[^bailey]。

10月26日、Geoff Graham はサイトの持ち主になったと発表した[^new-owner]。

## 独立後の方針

Graham は CSS-Tricks を本業にし、小さなチームで運営するとした[^new-owner]。発表で挙げた計画は次のとおりである[^new-owner]。

| 項目           | 計画                                                  |
| -------------- | ----------------------------------------------------- |
| 収入           | DigitalOcean 以前のように、表示広告や記事広告を売る   |
| 会員           | 会員の制度を始め、Discord の会員向けの場を設ける      |
| 講座           | 初心者向けの HTML と CSS の講座を作っている           |
| ニュースレター | 長く止まっていたものを再開する                        |
| 記事           | しばらくは週に1本か2本に減らす                        |
| 寄稿           | 寄稿の受付を再開する。AI に書かせた雑な原稿は読まない |

Graham は、自分が書くよりも書き手に場を与える発行人の役を務めたいと書いている[^new-owner]。初心者が入りやすい場にすることも目標に挙げた[^new-owner]。
