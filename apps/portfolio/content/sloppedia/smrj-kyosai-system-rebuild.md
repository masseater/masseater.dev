中小機構の共済システム再構築は、独立行政法人の中小企業基盤整備機構（中小機構）が、2つの共済事業を支える古いシステムを作り直しているプロジェクトである。新しいシステムは予定の2025年8月に稼働できず、稼働は2027年2月まで延びた。関連する契約の額は当初の555億円から962億円に増え、2026年3月末までに679億円が支払われた。会計検査院は2026年10月21日、中小機構に是正の処置を求め、中小機構と中小企業庁に意見を示した[^jbaudit]。

## 背景

中小機構は、小規模企業共済と中小企業倒産防止共済の2つの事業を運営している。制度は中小企業庁が受け持ち、中小機構は実施機関にあたる[^jbaudit]。

| 事業                 | 中身                                                                   | 2025年度末の加入者 | 2025年度末の勘定の資産 |
| -------------------- | ---------------------------------------------------------------------- | ------------------ | ---------------------- |
| 小規模企業共済       | 個人事業主などが事業をやめたときに共済金を払う                         | 約172万            | 16兆3942億円           |
| 中小企業倒産防止共済 | 取引先が倒産して売掛金が回収できないとき、共済金を無利子・無担保で貸す | 約67万             | 3兆4139億円            |

加入者の情報、掛金の収納、貸付金の支払いなどを処理するのが共済システムである。今のシステムは1975年に富士通が開発した。その後も制度が変わるたびに改修されたが、大きく作り直したのは1995年が最後だった。会計検査院は、技術が古くなり、肥大化と複雑化が進み、中身が分からないブラックボックスになった「レガシーシステム」だと書いている。サーバーに使う富士通のメインフレームは、2035年度で保守が終わると富士通が発表している[^jbaudit]。

## 計画

中小機構は2018年4月に共済制度の改革を進める室を設けた。申請の手続きをオンラインにするなど業務の流れを全面的に見直し、それに合わせてシステムを作り直すことにした[^jbaudit]。

2021年9月の全体計画書は、政府の「デジタル・ガバメント推進標準ガイドライン」に従うと定めた。作り直しの手法は、今の業務と処理の中身をもとにゼロから作るリビルドである。開発の進め方はウォーターフォール型で、設計、開発、テストを順に進め、前の工程が終わってから次に移る。2022年4月の基本設計から始めて、2025年8月に稼働させる予定だった[^jbaudit]。

主な契約は5つで、いずれも当初の額である[^jbaudit]。

| 段階               | 相手                                      | 役割                               | 当初の額  |
| ------------------ | ----------------------------------------- | ---------------------------------- | --------- |
| 全体計画と要件定義 | アクセンチュア                            | 全体計画書と要件定義書を作る       | 24.2億円  |
| 全体計画と要件定義 | PwC コンサルティング                      | プロジェクト管理と発注者の支援     | 2.3億円   |
| 設計開発           | 日本アイ・ビー・エム                      | アプリケーションの設計、開発、保守 | 206.8億円 |
| 設計開発           | EY ストラテジー・アンド・コンサルティング | プロジェクト管理                   | 15.3億円  |
| 設計開発           | アクセンチュア                            | 発注者の支援（随意契約）           | 70.0億円  |

ほかにも、今のシステムの調査を富士通に、インフラの構築を東芝デジタルソリューションズに頼むなどしている。関連する契約は全部で26件、当初の額の合計は555億4661万円だった[^jbaudit]。

## 遅れと費用の増加

要件定義書は予定どおり2021年9月にまとまり、2022年3月に日本アイ・ビー・エムと設計開発の契約を結んだ。しかしその後、機能を足す必要が何度も出た。2026年3月末までに設計開発の契約を8回変更し、17の業務を足した[^jbaudit]。

稼働の時期は2度延びた。2024年8月に2025年8月から2026年9月へ、2025年9月にさらに2027年2月へ延ばした。業務が増えて開発の規模が広がり、ウォーターフォール型のはずが、基本設計から受入テストまでの工程が同時に進む形になった[^jbaudit]。

関連する契約の額は、2026年3月末で962億6777万円になり、当初の約1.7倍になった。支払いは679億3028万円に達した。2度目の延期に合わせた変更をまだ結んでいない契約もあり、額はさらに増える見込みである[^jbaudit]。

中小企業庁は、1度目の延期の報告を受けた2024年3月に、遅れの原因を調べて再発を防ぐよう中小機構を指導した。それでも2度目の延期は防げず、2025年12月に改めて原因の究明とプロジェクト管理の徹底を指導した[^jbaudit]。

## 原因

会計検査院は、足された17の業務のうち13が、中小機構の進め方が適切でなかったために生じたと認めた。この13業務で増えた契約の額は365億0961万円である。そのうち46億5392万円は、作り終えたプログラムを作り直すといった手戻りの費用だった。原因は4つに分けられている[^jbaudit]。

| 原因                                                   | 増えた額  | うち手戻り |
| ------------------------------------------------------ | --------- | ---------- |
| 今のシステムの仕様を調べなかった                       | 44.1億円  | 23.9億円   |
| 今のデータの仕様を調べず、富士通の支援も確かめなかった | 205.8億円 | なし       |
| 情報セキュリティの検討が足りなかった                   | 19.5億円  | なし       |
| 新しい業務の流れが実現できるか確かめなかった           | 30.4億円  | 4.5億円    |
| 法令の要件を要件定義書に書かず、伝えもしなかった       | 51.7億円  | 18.1億円   |

残りの13.5億円は、開発とテストを並行して進めるために足したテスト環境の分である[^jbaudit]。

### 今のシステムの仕様

中小機構は、改修のたびにその箇所のマニュアルや設計書を作るだけで、全体を整理し直してこなかった。このため、プロジェクトを始めた時点で、今のシステムで何をしているのかが十分に分かっていなかった[^jbaudit]。

2021年7月から8月の情報提供依頼（RFI）で、富士通は意見を出していた。レガシーシステムは設計書が整っていないことが多く、ソースコードを読んでも業務の意味や背景は分かりにくいので、仕様を追加で調べるべきだというものだった。しかしアクセンチュアは、法令とソースコードなどがあれば設計できるとした。PwC コンサルティングも異を唱えず、中小機構は追加の調査をせずに要件定義書をまとめた[^jbaudit]。

例として、倒産防止共済の決算では、今のシステムからリスク管理債権の帳票を出して、破綻した貸付先などへの債権を整理している。中小機構はこの帳票の存在を把握しておらず、要件定義書に書かなかった。2023年6月までに、この帳票を扱ったことのある職員が気づき、出力する機能を3億4472万円で足した[^jbaudit]。

### 今のデータの仕様

中小機構は、予定どおり稼働させるには早く設計開発に入る必要があるとして、今のデータを調べないまま要件定義書をまとめた。設計開発の仕様書には、日本アイ・ビー・エムの質問に富士通が答えると書いたが、富士通が応じるかを事前に確かめていなかった。契約の後、日本アイ・ビー・エムは想定した支援を富士通から受けられないと分かった[^jbaudit]。

その結果、移行するデータの見直しや検証のテストが足された。移行データの検証テストだけで109億2520万円かかり、ほかの契約の変更も合わせて増えた額は205億7941万円になった。1度目の延期は、このデータ移行の品質を保つためだった[^jbaudit]。

例として、今のシステムはデータを主なファイルのほかに、ディスクの上にテープのような領域を作る仮想テープにも置いている。中小機構とアクセンチュアは、仮想テープにはバックアップだけがあると考え、移行の対象に入れなかった。2024年3月に調べたところ、仮想テープにしか無いデータもあると分かった[^jbaudit]。

### 情報セキュリティ

ガイドラインは、セキュリティのような機能以外の要件について、RFI などで広く情報を集めてから要件を決めるよう求めている。中小機構は RFI で情報セキュリティ対策を依頼の項目に入れなかった。2022年6月に日本アイ・ビー・エムのシステム構成案を検討すると、データを扱うネットワークに侵入されるおそれが見つかり、ネットワークの構成を変える業務が足された[^jbaudit]。

### 新しい業務の流れ

中小機構は、小規模企業共済の貸付けを、オンラインで申し込みから返済までできる新しい制度に移すつもりだった。今の加入者の同意を個別に取らず、一括で移すことを前提にしたため、今の貸付制度の機能を要件定義書に書かなかった[^jbaudit]。

要件定義書をまとめた後の2022年3月、顧問弁護士は、振込手数料がかかるなど加入者に不利益が出るので個別の同意が要り、一括での移行は難しいと答えた。中小機構はその後の検討に時間がかかったとして、今の貸付制度の機能も必要だと日本アイ・ビー・エムに伝えたのは2023年3月だった。その間に作った基本設計書は作り直しになった[^jbaudit]。

### 法令の要件

中小機構とアクセンチュアは、日本アイ・ビー・エムが法令を見て設計するだろうと考え、法令と運用の実態から来る要件を要件定義書に十分に書かなかった。中小機構は基本設計の工程でもそれを伝えず、基本設計書は法令や運用の実態と違う中身になった。中小機構と発注者支援のアクセンチュアは、確認の体制を作らないまま基本設計書を確かめ、違いを見落としたまま検収した[^jbaudit]。

例として、法令では、加入者が掛金の額を変えたときの効力は、申込書を受け取った日の月に生じる。中小機構の職員には周知のことだったので、日本アイ・ビー・エムへ伝えていなかった。基本設計書は、中小機構が承認した日の月に効力が生じる仕様になっていた。中小機構では、人事異動で業務に詳しくない人も設計書を確かめることになったが、確認する項目とマニュアルは整っていなかった。2023年10月に確認を終えて検収した後、2024年3月の担当課からの問い合わせで違いが分かった。直す業務に32億8894万円かかり、そのうち13億2756万円が手戻りだった[^jbaudit]。

この修正で一度終えた基本設計を見直す必要が出たため、稼働は2027年2月に延びた[^jbaudit]。

## 会計検査院の判断

会計検査院は、原因にはアクセンチュアと PwC コンサルティングの対応もあるとした。アクセンチュアは、仕様の把握の状況と今のシステムの資産を使えば予定どおり作り直せると考え、基本設計書の確認の体制も作らなかった。PwC コンサルティングはその見解に異を唱えなかった[^jbaudit]。

そのうえで主な原因は、中小機構がガイドラインの求める手順の大切さを十分に理解していなかったことと、中小企業庁の指導が足りなかったことだとした。さらに、工程が同時に進んで管理が複雑になったことと、設計書の確認の体制が弱かったことから、開発中のシステムにまだ見つかっていない不具合が潜んでいるおそれがあると書いた[^jbaudit]。

中小機構は、加入者の利便性を上げるためにプロジェクトを続けて稼働を目指すとしている。会計検査院の求めは次の表のとおりである[^jbaudit]。

| 相手       | 根拠                 | 中身                                                                                       |
| ---------- | -------------------- | ------------------------------------------------------------------------------------------ |
| 中小機構   | 会計検査院法の第34条 | 是正の処置。必要な品質があることを十分に確かめてから稼働させ、懸念が出たら対応する         |
| 中小機構   | 会計検査院法の第36条 | 意見。今後ほかのシステムを作り直すときに、ガイドラインに沿って整備と運用ができる体制を作る |
| 中小企業庁 | 会計検査院法の第36条 | 意見。中小機構の対応が確実に行われるよう指導と助言をする                                   |

[^jbaudit]: 会計検査院「[共済システムの再構築について](https://www.jbaudit.go.jp/report/new/kobetsu07/pdf/081021_zenbun.pdf)」2026年10月21日。
