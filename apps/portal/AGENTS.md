# portal

This workspace is portal.masseater.dev, a personal portal only the owner can enter. It shows watashi, money, slides and credentials in one place.

- It keeps no data. It reads from the RPC entry points of the Workers that hold the data (`@masseater.dev/portal-protocol`) and from the personal.masseater.dev service binding.
- It shows the owner's information, so do not make changes that move it outside Access.
