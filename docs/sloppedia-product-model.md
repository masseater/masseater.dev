# Sloppedia のプロダクトモデル

Sloppedia の今後の形を定めた文書である。実装の方法は扱わない。持ち主が2026年11月5日に示した2つの考えを元にしている。1つ目は、形態素解析で取り出した単語を、すべて Wiki の記事にしていくことである。2つ目は、記事ができるまでに貢献した人を何らかの形で扱うことである。

## 何か

Sloppedia は、文章に出てきた単語を1つずつ百科事典の記事にしていく個人の Wiki である。記事が増えると、その本文から新しい単語が出てくる。その単語もまた記事の候補になる。

今の Sloppedia では、持ち主か AI が題材を1つ決めて記事を書いている。これからは、題材を人が選ぶのではなく、本文の単語から機械的に候補を出す形に変える。

## 使う人

| 役割                | する事                                                                     |
| ------------------- | -------------------------------------------------------------------------- |
| 持ち主（masseater） | 記事を公開する最終の判断をする。方針を決める                               |
| 貢献者              | 記事を作るきっかけと材料を出す。どこまでの行為を貢献に数えるかは未決である |
| AI                  | 候補の単語から記事の下書きを書き、出典を集める                             |
| 読み手              | 記事を読み、記事から記事へたどる                                           |

## 中心の循環

1. 元の文章を形態素解析にかけ、単語を取り出す。元の文章は、既存の記事や持ち込まれた資料である。
2. まだ記事の無い単語を候補にする。
3. 候補から記事を作る。
4. できた記事の本文がまた次の元の文章になり、1に戻る。

この循環で、記事の数と記事の間のリンクが同時に増える。ある記事の本文にある単語は、その単語の記事へのリンクになる。

## 用語

| 用語   | 意味                                                   |
| ------ | ------------------------------------------------------ |
| 単語   | 形態素解析で取り出した、記事の見出しになりうる語である |
| 候補   | まだ記事の無い単語である                               |
| 記事   | 1つの単語を見出しにした百科事典の体裁のページである    |
| 由来   | ある候補がどの記事のどこから出てきたかの記録である     |
| 貢献   | 記事ができるまでに人が行った行為である                 |
| 貢献者 | 1つ以上の貢献をした人である                            |

## 貢献

貢献に数える行為の候補を次に挙げる。どれを数えるかと、重みを付けるかは未決である。

| 行為     | 例                                       |
| -------- | ---------------------------------------- |
| 持ち込み | 元の文章や資料を出す                     |
| 依頼     | ある候補を記事にするよう頼む             |
| 指示     | 書き方や中身を直すよう指示する           |
| 修正     | 記事の誤りを見つけて直させる             |
| 由来の元 | 自分が貢献した記事から、新しい候補が出る |

## 見せるもの

読み手に見せる候補は、記事ごとの貢献者、記事の由来、記事の間のリンクである。由来は、どの記事から生まれたかの系譜として見せる。まだ記事の無い候補の一覧を見せるかどうかは未決である。

## 扱わないもの

編集の画面は作らない。記事を書く経路は今と同じく、持ち主の依頼を受けた AI が PR を出す形に限る。

貢献者への報酬や順位付けで競わせる仕組みも作らない。

## 未決の事項

| 事項           | 内容                                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------------- |
| 貢献者の範囲   | 今の編集者は持ち主だけである。外の人を貢献者にするのか、持ち主が依頼したことの記録にとどめるのかを決める |
| 貢献の数え方   | 上の表のどの行為を数え、重みを付けるかを決める                                                           |
| 単語の粒度     | 複合語を1語として扱うか、分けるかを決める。固有名詞の扱いも決める                                        |
| 除外する単語   | 一般的すぎる語（「こと」「する」など）をどう外すかを決める                                               |
| 記事にする基準 | すべての候補を記事にするのか、何かの基準で選ぶのかを決める                                               |
| 公開と検索     | 今は noindex である。貢献者を見せるなら、外から見つけられるようにするかを決める                          |
| 本人の確認     | 貢献者をどう識別し、名前を出す同意をどう取るかを決める                                                   |
